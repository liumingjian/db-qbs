屏 A · 数据源屏：导航第三项，整屏由既有元素拼成

信息架构只加一项：任务 / 运行历史 / 数据源。数据源不是任务的子物， 它被多个任务共享、独立增删改，塞进任务屏就要在建任务的同时管凭据——那正是 ADR-0037 §7 「删除时若仍有任务引用它则拒绝」要防的耦合。位置放在两项之后：它是**先建一次、之后很少回来**的东西， 不该占第一项。这一项落在 README §7「导航占位项」旁边，**不动导航组件本身**。 不给过滤条、不给类型筛选：现场只有 3~5 个数据源（所有者 2026-08-19 确认）， 一屏看得完，搜索框是纯噪音——任务屏那条工具条是因为任务会长到几十个才有的。 列表里也没有「连接状态」列——那要么得后台轮询所有库，要么显示一个过期的绿点， 两者都比不显示更坏（同 ADR-0026「禁用状态本身会说谎」的态度）。连不连得上，点「测试」当场问。

屏 B · 新建 / 编辑数据源：一套对话框，两类字段

类型是建时选、编辑时不可改——改类型等于换一个数据源，而任务已经按 id 绑定了它 （ADR-0037 §8）。字段集直接照 ADR-0037 §6：Oracle 三个、MySQL 五个，不存 DSN 串。 口令是只写字段：编辑时永远显示为空并挂「已设置」徽标，留空提交 = 不改（§5）。 「测试连接」用的是表单里当前填的值，不是库里存的那份——否则改完口令没法验证； 编辑态口令留空时，测试用已存的那份口令，与保存的「留空 = 不改」是同一条解释规则。 测通才让存（所有者 2026-08-19 裁定）：没测过或测失败，保存按钮禁用。 连接字段一改，上一次的结果当场作废、要重测；只改名称不要求重测——那组连接值没变， 重测买不到任何新信息，却要求库当时在线。 失败复用既有 .form-error，不出错误码标签：test-connection 不属于任何 run， 画一个 SINK_ENVIRONMENT 标签会让人以为这是一次运行的失败（README §3 轴三只服务于 run）。

屏 C · 删除被引用的数据源：拒绝，并把引用它的任务点名列出

ADR-0037 §7 定了拒绝（409），但只说「拒绝」不够用——只回一句「仍有任务引用」，人得自己去任务屏一个个翻。 把任务名列出来是零成本的（那份引用计数本来就要查才能判 409）。 这不是新元素：既有删除对话框 .delete-copy 的正文里多一段列表。

屏 D · 构建器：目标端一段（可过滤下拉 + 目标列参考）

目标表从文本框升级为可过滤下拉（ADR-0038 §3）。做法是原生 <input list> + <datalist>：零新组件、零新 CSS， 浏览器自带子串过滤与键盘操作，并且**打字仍然能打**——记得全名的人不必翻列表。 代价写明：datalist 的下拉样式归浏览器管，我们标不了每项副标（Safari 下体验略糙）。 换自绘 combobox 要新增一整个组件与一套键盘可达性，第一版不买。 下方「目标表列（参考）」是 POST /v1/target/columns 的结果，只亮不判 （ADR-0038 §3 末段）：PK/UNIQUE 摆在旁边供参考，但主键是用户勾的； 未被映射的列压暗显示，它是事实不是待办。这份结果刷新即丢（§8）。

屏 E · 构建器：源列与映射两栏（本票的密度靶子）

既有的六列表（选择 / 主键 / 列名 / 字典类型 / 精度长度 / 可空）加一列「目标字段」， 默认预填源名——那不是将就的默认值，它就是恒等映射的正确表达（ADR-0038 §2）。 主键那一列勾的是目标列名（§6）：改了别名，主键跟着改，界面上因此把主键勾选放在目标字段右边、 不再放在最左——勾的东西要挨着它指的那个名字。未选中的行，目标字段输入框禁用并压暗。 「长度（字符）」这个表头就是 ADR-0038 §10 要求的单位标注； 脚下那句静态说明是同一条 §10 要求的时效交代，零判定、零元数据。

变体对照 · 目标字段控件：常驻输入框（A，推荐）vs 点开才编辑（B）

这一格要你来判，因为它取决于现场怎么用：多数列都要改名，还是十列里偶尔改一个。 A 把输入框常驻，改名零点击、一眼看得出「哪一列被改过」需要靠对比两栏； B 默认只显示文字（同名时留一个「＝」），点笔才变输入框，屏幕安静、改过的列自带痕迹， 但每改一列多一次点击。两者都不新增组件，代价只在点击数与视觉噪音之间。
