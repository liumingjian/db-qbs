## 八、清单外的观察

1. **形状预检卡的副标题仍是英文。** 形状预检失败屏第一张卡的第三行是
   `source-local SQL shape precheck found 3 problem(s)`——直接来自子进程日志的 `message` 原文。
   同屏的结论条与六条规则说明本轮都是中文，**只有这一行是英文**。
   与 #90（成功结论条英文）是同一类账，但位置不同：那条在结论条，这条在卡副标题。
   **本轮不改，另开票记账。**
2. **失败结论条前多了方括号类目名。** 本轮新增：映射预检失败读作
   `[类型映射] 目标端：映射预检未通过：…`，哨兵逃逸读作 `[程序缺陷] 目标端：预检哨兵逃逸，请报 issue`。
   这是 ADR-0029 §3 定的分类落地位置——**只加文字、不加视觉元素**，走查清单里没有对应条目，
   在此记账。观感上它与错误码标签并排出现时略有重复（标签给码、前缀给类），
   但两者信息不同：码是协议的，类目是排障的第一刀。
3. 上一轮记的 #90 已在本轮修掉（见 V2），历史列表与运行详情两处都变中文。
