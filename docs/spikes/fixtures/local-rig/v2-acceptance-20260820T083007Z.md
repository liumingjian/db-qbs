### 前两轮派发的失败是环境，不是判据

第一次派发 M2/M3/v1 三份都停在 `rig preparation failed`，两轮原因都在演练台之外：
没给 `M2_ORACLE_CLIENT_LIB_DIR`；给了之后那台 mac 缺 `x86_64-apple-darwin` 这个 rust target
（Oracle 从未出过 macOS arm64 的 Instant Client，宿主那半必须编成 x86_64 走 Rosetta，
本目录 README「arm64 mac：宿主那半必须是 x86_64 + Rosetta」一节写过）。
**这两轮没有产生任何判据读数**，补齐环境后的第三轮就是上表。记在这里是因为下一台机器会再撞一次。
