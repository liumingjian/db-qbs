## 〇、先说三处**探针自己坏掉了**，这一轮一并修好

这三条判据此前落在错的对象上——实录看上去正常，量的却不是判据说的那个东西。

| | 实测 |
|---|---|

## 一、本轮改了形态的三条

### X5 / X6：构建器 · 目标端与映射

**三层嵌套拆平了。** 原来是「目标表 > 目标表列参考 > 字段映射」——三张卡描述同一批列。
实测 `mapping_nested_in_structure = false`：「字段映射」与「目标表结构」现在是**兄弟**。

目标表结构默认收起：`{open: false, expanded: "false", rows_rendered: 0}`，
折叠头写 `目标表结构` + `5 列 · 只读参考，不写入任务定义`。
展开后五行原样在，未映射的两行仍然压暗——
`CREATE_TIME` / `ROW_NO` 的 `class = "is-unmapped"`、`color = rgba(0,0,0,0.45)`，
其余三行 `rgba(0,0,0,0.85)`。**X6 原判的这一半一字未变**。

映射卡的头改成了「机器做到了多少」：实测副标题 `3 列已映射，无需确认`，
两颗键 `同名填充` / `清空映射` **并排一行**（`.field-mapping-section > header > .field-mapping-actions`
要压过 `header > div { flex-direction: column }`，否则会竖着摞两颗——第一次跑出来就是竖的，已修）。

映射表五列不变：`源列 · 目标字段 · 目标类型 · 约束 · 主键`，目标字段仍是**常驻 `SELECT`**。
1024 与 1440 各看一次：控件高 26 / 行高 43，三行 `control_fits_row` 全 `true`，
1024 下 `table_overflow_x = 0`（没撑破），`dark_theme_media = 0`（第一版仍无暗色主题）。
改一个目标字段主键跟着走：`ID → C_NAME`，`key_still_checked = true`。

### X8 / X14：作业中心「源表」列

**这一列原来对自定义 SQL 的任务渲染成一个孤零零的 `.`**（`owner` / `table` 都是空串）。
桩这轮补了一条这样的任务（`task-sqlmode`「客户订单增量」），七行逐格实测：

| 行 | `.table-cell` 文本 | `title`（全文） |
|---|---|---|
| 前六行 | `APP.T_HOLDING` | `APP.T_HOLDING` |
| 客户订单增量 | `自定义 SQL` 徽标 + `SELECT * FROM APP.T_HOLDING@POC_LINK_A WHERE STA…` | `SELECT *\n  FROM APP.T_HOLDING@POC_LINK_A\n WHERE STATUS = 1` |

七格都是**两个子元素**（上行表名 / 下行数据源名），X8 原判的「每格两行、下行给名字不给 id」
原样成立。七格的 `font-variant-ligatures` 实测全是 `none`——
`>=` 不会再被 JetBrains Mono 画成 `≥`。

X14 列序实测仍是九列 `☐ · 任务名 · 源表 · 目标表 · 迁移进度 · 运行状态 · 启动时间 · 运行时长 · 操作`，
`absent_columns = []`（主键 / 条件 / 错误码 / 目标表效果一个都没混进来），
1024 下 `table_overflow_x = 686`（横滚而不是挤烂）。

### 过滤条件卡（X 系列没有专条，随 X5–X7 的截图记录）

列序与列宽按「手要落在哪」重排：`字段 · 比较 · 值 · 值类型 · 删除`——
「值」是唯一要手打的格子，原来它比只放 `>` `<` `=` 的下拉还窄。
副标题补了「多条按 AND 连接」，脚注写明比较符只有三种、更复杂的条件改用自定义 SQL。
自定义 SQL 模式下这张卡**不再整个消失**，留一句「过滤与排序请直接写进上面的 SQL」。

## 三、这一轮**没有**观察到的一件事，如实记下

**「同名列在读取目标列时自动接上」这条新行为没有被走查覆盖。** 桩里的任务规格
（`SPEC`）三列的目标字段本来就填好了，自动填充只补空位、不覆盖已选，
所以走查这条路径上它没有对象——实测副标题是 `3 列已映射，无需确认`，
而不是 `已自动匹配 3/4，1 个待确认`。
这条行为的正确性目前只由代码里「只填 `target === ""` 的映射」这一条守着，
要真正入门禁得给桩加一条「目标字段全空、但列名与目标表同名」的任务规格。
本轮不擅自加——那会改动 X8 / X14 / X16 / X17 的取样对象。
