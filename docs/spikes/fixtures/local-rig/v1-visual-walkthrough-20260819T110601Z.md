填 `HOLDING` 失焦后出「目标表列参考」卡，表头实测七列
`目标表列 / 类型 / 长度（字符）/ 可空 / 默认值 / 约束 / 映射自`，5 行逐行实际内容：

| 目标表列 | 类型 | 长度（字符） | 可空 | 默认值 | 约束 | 映射自 | 行类名 / 正文色 |
|---|---|---|---|---|---|---|---|
| `ID` | `bigint(20)` | — | 否 | — | `PRIMARY` | `ID` | 无 / `rgb(23,35,61)` |
| `C_NAME` | `varchar(200)` | 200 | 是 | — | `UNIQUE u_code` | `C_NAME` | 无 / `rgb(23,35,61)` |
| `LOAD_DATE` | `datetime` | — | 是 | — | — | `LOAD_DATE` | 无 / `rgb(23,35,61)` |
| `CREATE_TIME` | `datetime` | — | 否 | `CURRENT_TIMESTAMP` | — | **（未映射）** | `is-unmapped` / **`rgb(128,134,149)`** |
| `ROW_NO` | `int(11)` | — | 否 | — | — | **（未映射）** | `is-unmapped` / **`rgb(128,134,149)`** |

**只亮不判验到了**：`PRIMARY` 与 `UNIQUE u_code` 只摆在「约束」栏，主键仍由用户在左边那张表勾；
`ROW_NO` 是「未映射 + 非空 + 无默认值」——**预检会拒的那一类，这里一个拦截都没有**，
只是整行压暗（正文色从 `--text` 换成 `--mute`）。卡片脚注实测：
「这份结果**刷新即丢**：它不进任务定义、不进 SQLite（ADR-0038 §8）。」+
「长度栏同为字符；映射预检按字节判。」

**X6（映射两栏 · 1024 与 1440 各一次）**：表头实测七列，顺序
`选择 / 列名 / 字典类型 / 精度 / 长度（字符） / 可空 / **目标字段** / **主键**`——
**主键已从最左挪到目标字段右侧**。逐行实测（两个视口逐字相同，只有横坐标不同）：

| 列 | 选择 | 目标字段值 | 目标字段禁用 | 主键 | 主键禁用 |
|---|---|---|---|---|---|
| `ID` | ✓ | `ID`（常驻输入框） | 否 | ✓ | 否 |
| `C_NAME` | ✓ | `C_NAME` | 否 | ✗ | 否 |
| `LOAD_DATE` | ✓ | `LOAD_DATE` | 否 | ✗ | 否 |
| `N_AMT` | ✗ | `N_AMT` | **是** | ✗ | **是** |

- **常驻输入框**：每一行都有 `.cell-input`，**不是「点开才编辑」**——不需要先点一下才出现输入框；
  默认值就是源列名（恒等映射的正确表达）。
- **未选中的行双双禁用**：`N_AMT` 的输入框与主键勾选 `disabled` 都是 `true`，
  输入框走 `.cell-input:disabled`（`--mute-bg` 底、`--mute` 字）压暗。
- **等高、不撑破行**：输入框高 **26px**、行高 **44px**（两个视口都一样）；
  输入框右边缘 1440 下 `1104.9` / 单元格右边缘 `1116.9`，1024 下 `895.2` / `907.2`——
  **两个视口下输入框都在单元格内、留着 12px 右边距**。`.builder-columns` 的
  `scrollWidth - clientWidth` 两个视口下都是 **0**，没有横滚。
- **改目标名时主键跟着走**（ADR-0039 增补 1）：把已勾主键的 `ID` 改成 `CUST_ID_RENAMED`，
  **主键勾选仍然是勾上的**（`key_still_checked: true`）——没有出现「界面勾着、规格里是旧名」
  的中间态。两个视口各验一次。
- **第一版没有暗色主题**（ADR-0025 正面否掉，此处复核）：整份样式表里
  `prefers-color-scheme` 的 `@media` 规则 **0 条**。

**X7（长度栏单位标注）**：源列那张表的长度栏表头实测「**精度 / 长度（字符）**」，
目标列参考表的是「**长度（字符）**」。表下的静态说明实测原文：

> 长度栏的单位是**字符**，而**映射预检按字节判**（ADR-0033）：`utf8mb4` 下 10 个汉字是 30 字节。
> 第一版不统一两套口径，撞上时**以预检结论为准**。

computed style `color: rgb(128, 134, 149)`（`--mute`）、`background: rgba(0, 0, 0, 0)`、
`border-width: 0px`——**纯文字、不着色、不长成告警**（同 W3 的态度）。

> **一处与 ADR §7 字面不同、有意为之**：ADR 写「源列与目标列的长度栏表头**都写「长度（字符）」**」，
> 源列那一栏实际写的是「**精度 / 长度（字符）**」。理由是那一栏同时承载 `NUMBER` 的 `(p,s)`
> ——实测这一栏的值有 `(19,0)` / `(200)` / `(12,2)` 三种形态，把表头整个换成「长度（字符）」
> 会让 `(12,2)` 读起来像一个长度。**单位标注的目的达到了，歧义没有引入。**

**X8（任务屏）· 与 105426Z 一致**：七列，「源 → 目标」在第二位，
实测 `生产核心库 → 数仓 MySQL` / `财务库 → 数仓 MySQL`，是名字不是 id，不着色。
